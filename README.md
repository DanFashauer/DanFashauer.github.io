# Daniel Fashauer - Enterprise Platform Engineering & Architecture Portfolio

This repository is a static, GitHub Pages-ready portfolio.

## Recommended publishing setup

For the cleanest recruiter-facing URL, create a user site repository named:

`DanFashauer.github.io`

Then place these files in the repository root and enable **Settings -> Pages -> Deploy from a branch -> main / (root)**.

Your site will publish at:

`https://danfashauer.github.io/`

A project repository named `portfolio` also works, but the URL will be:

`https://danfashauer.github.io/portfolio/`

## Files

- `index.html` - portfolio site
- `styles.css` - responsive + print styles
- `Daniel_Fashauer_Portfolio.pdf` - attachment-friendly portfolio
- `.nojekyll` - keeps GitHub Pages from applying Jekyll processing
- `404.html` - simple fallback page

## Privacy / confidentiality

The portfolio intentionally uses reconstructed diagrams and anonymized descriptions.
Do not add screenshots containing employer names, credentials, tokens/API keys, internal URLs,
device identifiers, contact information, private ticket data, or non-public architecture.

## Updating

Edit `index.html` and `styles.css`, commit, and push. GitHub Pages will republish after the new commit is deployed.
