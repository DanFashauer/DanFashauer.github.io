# Daniel Fashauer - Enterprise Platform Engineering & Architecture Portfolio

## Focus

Selected, anonymized case studies across enterprise platform engineering, digital workplace, endpoint and mobility architecture, automation, REST API integration, and technical advisory work.

## Files

- `index.html` - self-contained responsive portfolio site

## Privacy / confidentiality

Professional examples are reconstructed and anonymized. Employer names, credentials, tokens/API keys, internal URLs, device identifiers, private ticket data, and non-public architecture are intentionally excluded from the public site.
